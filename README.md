# DadFit PWA

A progressive web app for a 10kg weight loss journey as a busy dad.

## Features
- 📅 Weekly workout schedule (Mon/Wed/Fri mornings + Saturday)
- ✅ Daily streak tracker  
- 🔔 Morning workout reminders
- 📊 Weight progress tracking
- 🍽️ Meal plan guide
- 📱 Installable as home screen app (PWA)

## Stack
React 18 · Service Worker · localStorage

## Dev
```bash
npm install
npm start
```

## Deploy
```bash
npm run build
```
Deploy `build/` to Netlify — connect this repo and it auto-deploys on every push.
